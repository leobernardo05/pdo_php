# 📚 Estudos de PDO com PHP

Este repositório reúne exemplos e exercícios práticos desenvolvidos durante meus estudos sobre **PHP Data Objects (PDO)**, a principal interface do PHP para acesso a bancos de dados de forma segura e orientada a objetos.

O objetivo do projeto é compreender os principais conceitos de conexão com banco de dados utilizando **MySQL** e aplicar boas práticas de desenvolvimento, como o uso de **Prepared Statements** para prevenção de ataques de SQL Injection.

## 🎯 Objetivos de Aprendizagem

- Compreender o funcionamento do PDO no PHP.
- Realizar conexões com bancos de dados MySQL.
- Executar operações CRUD (Create, Read, Update e Delete).
- Utilizar consultas parametrizadas (`prepare` e `bindValue`).
- Manipular exceções com `try/catch`.
- Entender boas práticas de segurança em aplicações PHP.

## 🛠️ Tecnologias Utilizadas

- PHP
- PDO (PHP Data Objects)
- MySQL (PHPMyAdmin)
- HTML

> **Observação:** A estrutura acima é apenas um exemplo e pode variar conforme o andamento dos estudos.

## 🚀 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/leobernardo05/pdo_php.git
```

2. Coloque o projeto em seu servidor local (XAMPP, WAMP ou Laragon).

3. Crie um banco de dados MySQL.

4. Atualize as credenciais de conexão nos arquivos PHP:

```php
$dsn = 'mysql:host=localhost;dbname=nome_do_banco';
$usuario = 'root';
$senha = '';
```

5. Execute os arquivos pelo navegador.

Este projeto possui finalidade exclusivamente **educacional**, servindo como registro da minha evolução nos estudos de **PHP**, **PDO** e **MySQL**, aplicando conceitos fundamentais para o desenvolvimento de aplicações web mais seguras e organizadas.
